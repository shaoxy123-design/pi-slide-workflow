# Planner: main Kimi session

This file binds the shared workflow to Kimi's actual built-in tools. All paths below are relative to the repository root; pass resolved absolute paths to workers.

For routine visual/layout choices, reuse supplied ideas and the prepared theme, optionally batch unresolved lookups through the local visual bank when useful, and record one decision per block in the existing plan. Read [fast local decisions](../../../docs/fast-decisions.md) only when using the batch helper. Kimi handles semantic ambiguity; search scores never approve changes or replace independent review. No Jev model or extra agent is used.

1. Confirm improve or create from the user's intent. Preserve originals in a unique `runs/<run-id>/`. Record requirements with ID, scope, acceptance check and status. Use the selected mode's defaults/contracts; brief the user in a few sentences, not an implementation checklist.
2. Bind one qualified editor, renderer and source/native-object inspection method using `docs/host-adapter.md`. Verify tools locally. Kimi cannot call Codex-only tools by naming them. Record gaps before promising a deck.
3. Use `question_me` from `skills/question-me/SKILL.md` through the native `AskUserQuestion` tool when needed. Ask one short consequential question when possible, never more than three at once. Use ordinary conversation if the tool is absent. Persist required questions; cancellation, headless operation or elapsed time never supplies an answer. Continue independent work.
4. Dispatch **Executioner** through native `Agent` with `subagent_type: "coder"`. Supply `hosts/kimi/agents/executioner.md`, the mode, original request, source hashes, plan/storyboard, tool choices and precise output paths. Save the returned worker identity; resume it for repairs using the advertised resume mechanism. Do not spawn other logical roles or use `AgentSwarm`.
5. After all candidate writes finish, verify the candidate hash and dispatch **Reviewer** through native `Agent` with `subagent_type: "explore"`, thorough inspection requested. Supply `hosts/kimi/agents/reviewer.md`, original requirements and sources before the edit narrative, the frozen candidate/hash, renders and raw evidence. The Reviewer has separate context and returns its report; save that report verbatim with its worker identity and candidate hash. Missing context must be explicitly passed, never assumed inherited.
6. Send concrete findings back to the Executioner, then recheck the repaired candidate. Package byte-identical reviewed output only after all required gates pass. Preserve missing/failed evidence and report blockers. No timed cutoffs, automatic cancellation or fixed repair cap.

**K3:** The CLI launcher explicitly selects a configured K3 alias; in Desktop, verify the selected model in the session. Keep thinking enabled for all three roles: thinking off routes K3 requests to a different model. Installed Kimi Code 0.27.0 inherits the primary model in its built-in workers. On another version, inspect the advertised `Agent` schema and effective worker binding before dispatch; request `model: "primary"` only when that parameter/value is advertised, and verify the primary is K3 with thinking enabled. Absence of `model` does not prove inheritance: `[secondary_model] force = true` hides the parameter and forces `default_model`, including its effective effort. Verify and record actual model/effort metadata for each worker, including resumes; do not fabricate missing evidence. If the binding is unknown or incompatible, ask the professor or report the blocker before continuing affected work. Do not change configuration or silently accept a different model. See official [worker bindings](https://www.kimi.com/code/docs/en/kimi-code-cli/configuration/config-files.html#secondary-model) and [thinking behavior](https://www.kimi.com/code/docs/en/kimi-code/models.html#how-to-switch-models).

Native transport or context limits are not workflow deadlines. If a worker is interrupted, reconcile persisted artifacts and hashes, then resume actionable work. Never report an interrupted or incomplete review as a pass.
